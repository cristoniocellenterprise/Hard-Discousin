# 💾 Hard Discousin — Repositorio IA

¡Bienvenido a **Hard Discousin**! Este es un repositorio web de código abierto diseñado para albergar, gestionar e interactuar con modelos de Inteligencia Artificial y bases de conocimiento locales a través de una interfaz limpia, tecnológica y optimizada para el modo oscuro.

## 🚀 Características Principales

*   🤖 **Interfaz de Chat Interactiva:** Comunícate en tiempo real con el modelo por defecto (`discousin-v2.5-llm`).
*   📂 **Explorador de Repositorios:** Barra lateral dedicada para la navegación rápida entre modelos disponibles y conjuntos de datos (Datasets).
*   🎨 **Diseño GitHub-Style:** Estética oscura moderna basada en componentes limpios y accesibles.
*   ⚡ **Ligero y Autónomo:** Todo el código principal se ejecuta directamente en el navegador sin dependencias pesadas de terceros.

## 🛠️ Estructura del Proyecto

El núcleo de la aplicación se compone actualmente de un único archivo estructurado:

```plaintext
└── index.html       # Interfaz de usuario, estilos (CSS) y lógica de simulación (JS)
```

## 💻 Instalación y Uso Local

Para ejecutar este repositorio en tu máquina local, no necesitas instalar ningún servidor o base de datos. Solo sigue estos pasos:

1.  **Clona o descarga** este repositorio.
2.  Asegúrate de que el archivo principal se llame `index.html`.
3.  Haz **doble clic** sobre el archivo `index.html` para abrirlo en cualquier navegador web moderno (Chrome, Edge, Firefox, Brave, Safari).

## 🧠 Modelos Disponibles (Simulados)

*   `discousin-v2.5-llm` (Activo): Modelo de lenguaje para procesamiento de texto general.
*   `discousin-vision-beta`: Capacidad de procesamiento y análisis de imágenes.
*   `deep-hard-drive-r1`: Modelo de razonamiento complejo y resolución de problemas lógicos.
